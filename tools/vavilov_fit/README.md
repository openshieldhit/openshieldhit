# vavilov_fit — offline straggling sampler tooling

Offline pipeline that produces the **reference fixtures** and the fitted
inverse-CDF **coefficients** for the Vavilov + Landau energy-straggling samplers.
Nothing here is compiled into the OpenShieldHIT C build.

## Provenance

The fitted inverse-CDF coefficients follow an **approach by Bjarne Thomsen**
(Dept. of Physics and Astronomy, Aarhus University, Aarhus, Denmark, 2012):
region branches in the transformed uniform deviate, with the per-region
coefficients expanded as Chebyshev sums in (κ, β).  OpenShieldHIT uses the
**pole-free polynomial** special case (denominator ≡ 1) of that form.

The shipped coefficients are **OpenShieldHIT-specific** — reproducibly
regenerated by the scripts below from the published distributions:

- `vavilov_exact.py` — exact Vavilov density from its published definition
  (Vavilov, Sov. Phys. JETP 5, 749 (1957); B. Schorr, Comput. Phys. Commun. 7,
  215 (1974)), via the imaginary-axis Bromwich (Fourier) integral with
  `scipy.special.sici`. Self-validated to machine precision against the
  closed-form moments `mean = γ_E − 1 − β² − ln κ`, `var = (1 − β²/2)/κ`.
- `gen_reference.py` → `ref_cache.npz` — dense exact inverse-CDF table (cache,
  git-ignored) so the fit avoids re-running the quadrature.
- `fit_vavilov.py` + `emit_coeffs.py` — fit and emit the Vavilov coefficient
  header; validated on the independent fixture grid.
- `emit_landau.py` — the universal Landau (κ < 0.01) reference is the standard
  DENLAN distribution from `scipy.stats.landau` (BSD), mapped to the physics λ
  convention by the exact affine `λ_DENLAN = (π/2)·λ_scipy + b` (the κ→0 limit of
  the exact Vavilov λ); fit and emit its 1-D coefficient header.
- `gen_fixtures.py` — writes `tests/fixtures/vavilov/*.csv`: golden
  `λ(u; κ, β²)` inverse-CDF tables the C unit tests validate the samplers
  against. Vavilov regime κ ∈ [0.01, 10]; u ≤ 0.995.

## Requirements (dev only)

    python3 -m pip install numpy scipy

## Usage

    python3 tools/vavilov_fit/vavilov_exact.py   # exact-Vavilov moment self-test
    python3 tools/vavilov_fit/gen_reference.py   # (re)build the fit cache
    python3 tools/vavilov_fit/gen_fixtures.py    # (re)generate the golden fixtures
    python3 tools/vavilov_fit/emit_coeffs.py     # fit + emit the Vavilov coeff header
    python3 tools/vavilov_fit/emit_landau.py     # fit + emit the Landau coeff header
