# Courses

This directory contains course-level teaching modules.  Course numbers are local
to the teaching material and are meant to keep a stable reading order:

- `00` is a practical entry point for new users;
- `01` introduces generic Monte Carlo transport ideas;
- later courses can be used independently when a class focuses on one physics
  area.

Course directories should contain:

- `index.md` with scope, audience, and prerequisites;
- `slides/` for lecture placeholders or slide sources;
- `exercises/` for student exercise sets.
