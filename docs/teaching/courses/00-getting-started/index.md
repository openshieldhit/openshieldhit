# 00 Getting Started

This practical course introduces OpenShieldHIT as a simulation tool before
asking students to study the underlying transport models.  It is the right place
for adapted introductory exercise sets and workshop material.

## Audience

Students who are new to OpenShieldHIT or to SHIELD-HIT-style input files.

## Learning goals

After this course, students should be able to:

- run a prepared case;
- identify the role of `beam.dat`, `geo.dat`, `mat.dat`, and `detect.dat`;
- change a simple beam or scoring parameter;
- inspect text or BDO output;
- make a first depth-dose or fluence plot.
