# 02 Beam Dynamics

This course focuses on beam descriptions used in treatment-planning and
transport calculations.

## Audience

Students who already know the basic input-file workflow and want to understand
beam phase space and clinical beam descriptions.

## Learning goals

After this course, students should be able to:

- interpret source size, divergence, and correlations;
- relate phase-space ellipses to Twiss parameters;
- understand spot lists and source-to-axis distance;
- predict qualitative changes in fluence and dose from beam-parameter changes.
