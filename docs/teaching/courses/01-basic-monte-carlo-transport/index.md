# 01 Basic Monte Carlo Transport

This course introduces generic Monte Carlo transport concepts that are useful
before studying detailed physics models.

## Audience

Students learning particle transport, Monte Carlo simulation, or computational
medical physics.

## Learning goals

After this course, students should be able to:

- explain histories, tracks, steps, and scoring estimators;
- use random numbers for sampling simple distributions;
- distinguish analog scoring from derived or averaged quantities;
- estimate statistical uncertainty from repeated or partitioned runs.
