# Shared slides

Placeholder for slide material shared across teaching courses.

Course-specific slides should normally live in the `slides/` directory of the
course that owns them.  Use this shared area only for introductory, overview, or
cross-course material.

Planned topics:

- OpenShieldHIT overview;
- input-file model: `beam.dat`, `geo.dat`, `mat.dat`, `detect.dat`;
- Monte Carlo transport vocabulary;
- interpreting scored output and statistical uncertainty.
